The `me4305` module identifies the custom firmware and exposes the exact source revisions and frozen-module inventory embedded during the build. Use it when recording which firmware produced a result or when checking that a board contains the expected build.

> [!note] Source snapshot
> This page describes [`me4305.py`](https://github.com/charlierefvem/micropython/blob/c8e6f5f896349825cafbeef4037dee2dd21b93a0/ports/stm32/boards/NUCLEO_L476RG/modules/me4305.py) at commit [`c8e6f5f896349825cafbeef4037dee2dd21b93a0`](https://github.com/charlierefvem/micropython/commit/c8e6f5f896349825cafbeef4037dee2dd21b93a0). The firmware workflow generates the private `_build_info` module that supplies build-specific values.

## Standard use

Import the module and call `info()` to print a compact firmware report:

```python
import me4305

me4305.info()
```

Application code may also read the module attributes directly when it needs to store or compare a particular value.

## API overview

> [!table]
> Public members of `me4305`.
>
> | Name | Kind | Purpose |
> | --- | --- | --- |
> | `FIRMWARE_NAME` | `str` | Human-readable firmware name. |
> | `CUSTOM_REPOSITORY_SHA` | `str` or `None` | Exact custom-firmware source commit. |
> | `MICROPYTHON_SHA` | `str` or `None` | Exact upstream MicroPython commit. |
> | `ULAB_SHA` | `str` or `None` | Exact upstream `ulab` commit. |
> | `FROZEN_MODULES` | `tuple` | Names of custom Python modules frozen into the firmware. |
> | `info()` | Function | Print the firmware identity and available build provenance. |

## Module attributes

### `FIRMWARE_NAME`

```python
me4305.FIRMWARE_NAME
```

**Value:** `"ME 4305 Firmware"`.

---

### Source revision attributes

```python
me4305.CUSTOM_REPOSITORY_SHA
me4305.MICROPYTHON_SHA
me4305.ULAB_SHA
```

Each attribute is a full Git commit SHA when the module runs inside a completed firmware build. When `me4305.py` is imported from a source checkout without the generated `_build_info` module, each value is `None` rather than a provisional or guessed revision.

---

### `FROZEN_MODULES`

```python
me4305.FROZEN_MODULES
```

**Returns:** A tuple of custom frozen-module names in a completed firmware build. It is an empty tuple when build provenance is unavailable.

The inventory includes private build-support modules as well as application-facing modules, so a leading underscore does not indicate that a module was omitted from the firmware.

## `info()`

```python
me4305.info()
```

Print the firmware name. In a completed firmware build, it also prints the custom source commit, upstream MicroPython commit, upstream `ulab` commit, and comma-separated frozen-module inventory. It then prints `sys.implementation`.

When build provenance is unavailable, it prints a clear notice instead of displaying guessed values.

**Parameters:** None.

**Returns:** `None`.

## Compatibility name

The firmware also contains `me405`, a compatibility module that re-exports this API for existing student code. New code should import `me4305` directly.
